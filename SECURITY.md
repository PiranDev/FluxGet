# Security Policy

Please **do not post credentials, download history, local access keys, or exploit details** in public GitHub Issues.

Until a private reporting channel is configured, use the GitHub repository's **Security → Report a vulnerability** feature if available. If it is not enabled, do not post sensitive proof-of-concept data publicly. Maintainers should enable private vulnerability reporting before publication.

Security-related components include the localhost API (`127.0.0.1:6874`), browser extension pairing, download paths, and update downloads. No claim of a completed external security audit is made.
